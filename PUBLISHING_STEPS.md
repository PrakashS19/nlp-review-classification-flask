# GitHub publishing
1. Review the recovered coursework notebooks for your university sharing requirements. They are your recovered work, but course data and assignment-specific material may have sharing restrictions. Remove `coursework_recovered/` from the public ZIP if required; keep it privately.
2. Create an empty PUBLIC repository `nlp-review-classification-flask`.
3. Upload all files from this ZIP (not the ZIP archive). Keep folder structure. GitHub's file browser uploader may not preserve empty folders; none are required.
4. Do not add the missing original coursework dataset or fabricated score screenshots.
5. Download the public CC0 Kaggle dataset to your own machine and run `python src/train.py --input data/womens_clothing_reviews.csv` to obtain real metrics for the **new** baseline.
6. Only then update README/resume with *independently reproduced* new-baseline results.
